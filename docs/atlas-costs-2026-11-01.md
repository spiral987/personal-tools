## 段階Dの追加（2026-11-01）

Supabase FreeとVercel Hobbyの契約を維持。自動削除用に `pg_cron` / `pg_net` と `vault-retention` Edge Function 1本を追加した。有料サービス・有料プランへの変更なし。10分ごとの関数呼び出しは、1日144回、30日で4,320回の計算。処理量に応じてDB・関数・Storageの無料枠を使用する。実際の消費量は今後の運用で確認する。

削除するのは、ユーザーがごみ箱へ入れて期限を過ぎた記録と、参照がなくなったアプリ内の原本だけ。Drive原本・ユーザーが出力したバックアップ・他のVercelプロジェクトには変更を加えない。Freeで休止や上限到達が起きた場合、自動整理が遅れる可能性がある。
