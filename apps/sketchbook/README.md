# Sketchbook

1200 × 800の一枚の紙に、ペン・指・マウスでアイデアを残す独立したNext.jsアプリです。

リポジトリのルートから `pnpm dev` でRecallと一緒に起動し、同じ入り口の `/sketchbook/` を開きます。個別の開発サーバーは `pnpm --filter @personal-tools/sketchbook dev`、内部ポートは3101です。共通のブラウザ保存領域とログインを使うには、Recallと同じ入り口・同じホスト名を使ってください。

- ストロークJSONを編集できる原本として保存。PNGは書き出し・非公開プレビュー用です。
- ペン／消しゴム、色、太さ、Undo／Redo、タイトル、複数スペース。
- 新規と編集中の下書き復元、保存済みの再編集、ごみ箱／復元。
- Recallのメモを着想元として関連付け、原本へ移動。
- ユーザーごとの保存領域、オフライン保存、再送、競合の両版保持。
- PNGとJSONの書き出し。JSONはスケッチとスペースを持ち運ぶ形式で、下書き・Recall本文・関連付けは含みません。
- 独立したPWA manifestと `/sketchbook/` に限定した公開画面のキャッシュ。オフライン起動の準備は本番モードのみです。

上限は一枚あたり2,000ストローク／20,000描画点です。上限に達したら保存し、新しい一枚へ進んでください。複数タブで同時に描きかけの下書きを編集する用途には対応しません。保存済みスケッチは更新番号で古い画面からの上書きを防ぎます。
